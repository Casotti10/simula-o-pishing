# Simulação de Phishing — Página de Conscientização

Página estática exibida para colaboradores que clicarem no link de uma
campanha interna e autorizada de simulação de phishing, com o objetivo de
reforçar boas práticas de segurança da informação.

Esta página **não coleta nenhum dado** do colaborador — é puramente informativa.

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla, sem frameworks)

## Como rodar localmente

1. Clone este repositório.
2. Abra a pasta no VS Code.
3. Instale a extensão "Live Server".
4. Clique com o botão direito em `index.html` → "Open with Live Server".

## Estrutura de pastas

- `index.html` — estrutura e conteúdo da página
- `css/style.css` — estilização
- `js/script.js` — interatividade (botão de confirmação de leitura)
- `assets/` — imagens/ícones (se houver)
